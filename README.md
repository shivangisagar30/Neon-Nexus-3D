# TechFest 2026 — Neon Nexus 3D Experience

This repository contains an interactive single-page TechFest website built with HTML, CSS, and JavaScript.

## 🌐 Live Demo

https://shivangisagar30.github.io/Neon-Nexus-3D/

## Files

- `techfest-3d.html` — the main interactive landing page.

## Overview

`techfest-3d.html` presents a futuristic tech festival concept called **Neon Nexus**. The experience combines:

- 3D scene effects using CSS transforms and animations
- Scroll-driven depth transitions
- Interactive hover states for cards and objects
- Dynamic visual elements like glowing rings, orbiting modules, and motion-responsive panels

## Features

- **Hero stage** with a rotating 3D cube, luminous sphere, and orbital modules
- **Enhanced 3D headline** with neon glow, layered depth shadow, and a standout futuristic title effect
- **Animated neon background** with slow gradient shifts and glow movement for a more immersive atmosphere
- **Scroll animation** that updates scene depth and glow intensity
- **Hover interaction** on feature cards that highlights stage elements and updates the scene
- **Responsive layout** for desktop and mobile screen sizes
- **Animated navigation** with smooth scrolling

## Usage

1. Open `techfest-3d.html` in your browser.
2. Scroll down to explore sections.
3. Hover over cards to trigger interactive stage updates.
4. Click `Launch Experience` to smoothly jump into the experience section.

## Customization

You can customize the demo by editing:

- the text content in the HTML
- CSS variables at the top of the `<style>` block for color themes
- animation timing and 3D transform values in the `<script>` section

## Inspiration

The page is designed for a TechFest or hackathon landing experience with a neon cyber-future aesthetic and interactive 3D visuals.
